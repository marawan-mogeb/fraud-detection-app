09 — Lessons Learned

Key Takeaways

Building this system taught us critical lessons about real-world ML engineering that go beyond textbook knowledge.

01

Class Imbalance is the Real Enemy

With only 0.13% fraud, standard cross-entropy gives >99% accuracy while catching zero fraud. Focal Loss and PR-AUC were essential — accuracy is a trap in imbalanced domains.

02

Feature Engineering Beats Model Complexity

Derived features like errorBalanceOrig and amount_ratio_orig carried more signal than raw inputs. The 8 engineered features significantly boosted detection over using raw columns alone.

03

Residual Connections Help Tabular Data Too

Skip connections aren't just for images. ResBlocks prevented gradient degradation in our deep tabular network and consistently outperformed plain feed-forward architectures.

04

Threshold Selection is a Product Decision

The optimal threshold depends on business cost trade-offs (missed fraud vs. blocked legitimate users). We learned to treat it as a tunable parameter, not a fixed 0.5.

05

Package the Whole Pipeline, Not Just Weights

Saving scaler parameters, feature names, and threshold alongside model weights in one checkpoint file made deployment reproducible and eliminated train/serve skew.
